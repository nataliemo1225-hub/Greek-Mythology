# Mythos — A Greek Mythology Knowledge Atlas

An immersive, encyclopedic web atlas of Greek mythology: gods and titans, heroes and kings, epic tales, creatures, and the great tragedies — presented with classical typography, artwork, and interactive maps.

## Features

- **Gods & Titans** — profiles of the Olympians, the primordial deities, and the Titan generation
- **Heroes & Kings** — Heracles, Perseus, Odysseus, Achilles, Theseus, Jason, and more
- **Epic Tales** — the Iliad, the Odyssey, the Titanomachy, the Golden Fleece, and other cycles
- **Creatures & Tragedies** — monsters, mythical beings, and the great tragic stories
- **Interactive maps** — the Greek world, the Trojan War, and Odysseus' wanderings
- **Full-text search** across the atlas

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS + shadcn/ui components
- Framer Motion animations
- React Router

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build outputs to `dist/`.
